## Format and Rendering

GitHub's support for rendering math is buggy. For example, it will fail to render curly braces, as in the expression $\{E_n\}_{n=1}^N$. The workaround is to delimit inline math with both dollar signs and backticks, and to use a code fence with the special "math" language designator for displayed math. The previous example then becomes $`\{E_n\}_{n=1}^N`$.
